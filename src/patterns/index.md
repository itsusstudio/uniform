## Rules

Patterns follow the [Rules](/start/rules/), like every screen. The one that
shapes them most is [No structure for one thing](/start/rules/#no-structure-for-one-thing).

The same page shapes repeat in every app, so someone who knows one of our
products already knows their way around the next.

A pattern only arranges components and layout classes. It adds no classes and
no CSS of its own. If a screen needs something Uniform doesn't have, the missing
piece becomes a component or a layout, and every pattern can use it. See
[Patterns add no classes](/start/rules/#patterns-add-no-classes).
