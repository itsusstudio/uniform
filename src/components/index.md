tune. Each one gets its own page with code you can copy, added one at a time.

## What every component page includes

Anatomy
: The parts of the component and the tokens each part uses.

Variants and states
: Every version, shown live, including hover, focus, disabled and error.

Code
: The HTML and the Rails partial, rendered from the same file as the live example.

Do and don't
: At least one pair taken from a real mistake, shown side by side.

Accessibility
: Keyboard behaviour, screen reader labels, contrast and target size.
